# Where the brand assets belong on GitHub

> Companion to [`design-system.md`](design-system.md). That file defines what the
> brand *is*; this one covers where it gets applied on GitHub.
>
> Written before the brand kit moved into this repo. The assets it names are now
> generated by `brand/make_brand.py` into `brand/dist/`, which is gitignored —
> committed copies for README use are established separately. The GitHub-side
> steps below are unaffected.


## 1. Social preview — the card people see when the repo link is shared

The most important one, because your LinkedIn post *is* a shared repo link.
Without it GitHub shows the grey default placeholder.

Repo → **Settings** → **General** tab, scroll to **Social preview** → **Edit** →
**Upload an image…**

File: `nescio-github-social.png`

GitHub's requirements: PNG, JPG or GIF, **under 1 MB**, at least 640 × 320 px,
1280 × 640 px for the best display. Yours is around 100 KB at the right aspect
ratio, so it fits.

Not retroactive: links already shared keep the old preview until each platform
refreshes its cache.

## 2. The logo in the README

Repositories have no avatar field of their own — the visible place for the mark
is the top of the README. Commit the file into the repo so it works everywhere,
including in cloned instances:

```
mkdir -p docs/assets
cp nescio-logo-mark.svg docs/assets/
```

And at the very top of the README, above the heading:

```markdown
<p align="center">
  <img src="docs/assets/nescio-logo-mark.svg" width="112" alt="NescioAI">
</p>

<h1 align="center">nescio</h1>

<p align="center">
  An agent crew for Claude Code where "I don't know" is a first-class answer.
</p>
```

Use the relative path, not an absolute raw.githubusercontent link — that way the
image survives forks and cloned instances.

If SVG in the README gives you trouble (GitHub renders it, but restrictively),
use `nescio-logo-mark.png` instead. It has a transparent background and works in
both light and dark themes.

## 3. Optional

- **Your profile picture:** github.com/settings/profile → Edit → Upload a photo.
  Only worth it if NescioAI is meant to be your primary identity — otherwise a
  photo is better left a photo.
- **Later, as an organisation:** if the project ever moves under its own GitHub
  org, `nescio-logo-badge.png` is the org avatar. Not worth it before then.
- **The diagrams in the README:** `diagram-crew.png` explains the crew faster
  than the agent table does. Same folder, same embedding.
